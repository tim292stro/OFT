# RX Mode (Receive)

RX mode reads QR chunks from a video file or webcam stream, rebuilds the split archive, and extracts the original file/folder.

Back to summary: [README](README.md)

## Purpose

Use RX when you want to recover transmitted data from QR content generated by TX mode.

## Required RX arguments

- `-RX`
- Exactly one input source:
  - `--video <path>`
  - `--camera <index>`
- `-o, --output <path>`

## Optional RX arguments

- `--work-dir <path>`
- `--keep-intermediate`
- `--sevenzip-bin <path-or-name>`
- `-p, --password <text>`
- `--expected-chunks <int>`
- `--idle-timeout <seconds>` (webcam mode)
- `--max-duration <seconds>` (webcam mode)
- `--strict-chunk-size`

## RX usage examples

### Recover from video

```bash
python OFT.py -RX --video ./Test_Output/roundtrip_tx.mp4 -o ./Test_Output/recovered -p ExampleSecretPassword
```

### Recover from webcam

```bash
python OFT.py -RX --camera 0 -o ./Test_Output/recovered --expected-chunks 500
```

### Strict chunk validation

```bash
python OFT.py -RX --video ./Test_Output/roundtrip_tx.mp4 -o ./Test_Output/recovered --strict-chunk-size
```

## RX behavior notes

- RX does not accept `--source`.
- RX accepts only one of `--video` or `--camera`.
- If chunk capture completes but extraction fails, common causes are:
  - Wrong password
  - Mismatch between TX and RX payloads
  - Corrupted or incomplete archive reconstruction
